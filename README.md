# TrayCalc

Небольшой калькулятор для Windows на Rust: живёт в системном трее, вызывается горячей клавишей и запоминает состояние между запусками.

## Что умеет

- один экземпляр: повторный запуск показывает уже работающий калькулятор;
- трей, горячая клавиша и выбор — блокировать её в других программах или нет;
- история вычислений;
- привычный ввод: стрелки, Home, End, Delete, Backspace и выделение текста работают в поле выражения;
- корректно понимает числа с пробелами: `1 000 000`;
- выбор десятичного знака: точка или запятая;
- тема, акцентный цвет, прозрачность, размер, позиция открытия и режим «поверх окон»;
- автозагрузка Windows.

## Сборка

Нужны Rustup и MSVC Build Tools для Windows. Для текущей конфигурации используется target `x86_64-pc-windows-gnullvm`.

```bat
rustup toolchain install stable-x86_64-pc-windows-gnullvm
build-rust.bat
```

Готовый комплект появится в `dist`: `TrayCalc.exe` и `libunwind.dll`. Эти два файла должны находиться в одной папке.

## Проверка

```bat
cargo +stable-x86_64-pc-windows-gnullvm test --target x86_64-pc-windows-gnullvm
```
